=== CÓMO INSTALAR EL SISTEMA DE REPARTO ===

1. Instalar XAMPP (desde https://www.apachefriends.org/)

2. Copiar la carpeta "sistemareparto" a:
   C:\xampp\htdocs\sistemareparto

3. Iniciar Apache y MySQL en XAMPP

4. Abrir phpMyAdmin: http://localhost/phpmyadmin

5. Crear una base de datos llamada "sistemareparto"

6. Importar el archivo "sistemareparto.sql":
   - Clic en la base de datos creada
   - Pestaña "Importar"
   - Seleccionar el archivo .sql
   - Clic en "Continuar"

7. Acceder al sistema:
   http://localhost/sistemareparto/login.html
